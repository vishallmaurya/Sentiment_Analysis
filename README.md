# 🌟 Sentiment Analysis - Frontend

## 📌 Overview
This is the **frontend** of the Sentiment Analysis Web Application, built using **React.js** as part of the **MERN stack**. It provides an intuitive and responsive user interface for entering text, receiving sentiment predictions, and contributing data for model improvements. The application also features **Google Sign-In** for secure authentication and is **hosted on AWS** for high availability and scalability.

## 🚀 Features
- **Modern UI** powered by **React.js**
- **Google Sign-In Integration** for secure authentication
- **Instant Sentiment Analysis** with real-time API communication
- **User Feedback System** to enhance model performance
- **Fully Responsive Design** for mobile and desktop compatibility
- **Secure and Scalable** frontend architecture with MERN stack
- **Deployed on AWS** for high performance and reliability

## 🛠 Tech Stack
- **React.js** - Core framework for building the UI
- **Axios** - For API requests
- **React Router** - For navigation
- **Google OAuth** - For authentication
- **AWS Hosting** - Ensuring smooth and scalable deployment

## 🏗 Setup & Installation
### 1️⃣ Clone the Repository
```bash
git clone https://github.com/vishallmaurya/Sentiment_Analysis
cd client
```

### 2️⃣ Install Dependencies
```bash
npm install
```

### 3️⃣ Set Up Environment Variables
Create a `.env` file in the root of the project and add:
```env
VITE_GOOGLE_CLIENT_ID=<your-google-client-url>
VITE_BACKEND_URL=<your-backend-url>
```

### 4️⃣ Start the Development Server
```bash
npm start
```

## 🚀 Deployment
- **Hosted on AWS** for high performance and scalability.
- Environment variables for API URLs should be configured in `.env`.
